## 🛠️ Tech Stack

This project is built with:

- Vite  
- TypeScript  
- React  
- shadcn-ui  
- Tailwind CSS  

All `shadcn/ui` components have been downloaded under `@/components/ui`.

## 🚀 Getting Started

To run the project locally:

**Install Dependencies**

```shell
pnpm i
```

**Start Preview**

```shell
pnpm run dev
```

**To build**

```shell
pnpm run build
```
